About memory and model training

This version supports persistent chat history and a visual knowledge vault. It does not change model weights or fine-tune Llama. Fine-tuning is a separate, more resource-intensive process that can be added later.

Keep the app running only in a Codespace or machine you trust. Don't expose it publicly without authentication, rate limits, and proper secret handling.
