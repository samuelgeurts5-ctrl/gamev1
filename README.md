# Littlewood Wilds — gamev1

A browser-based, top-down pixel-art survival and building prototype inspired by cozy farming/adventure games.

## Play locally
Open `index.html` in a modern browser. No build tools or downloads are required.

## Controls
- **WASD / Arrow keys:** move
- **E:** gather from a nearby tree, rock, or bush
- **1:** select campfire
- **2:** select fence
- **Click nearby ground:** place the selected structure
- **Esc:** pause or resume

## Current features
- Procedurally generated meadow with trees, rocks, bushes, and flowers
- Resource gathering and backpack counters
- Campfire and fence placement
- Day/night cycle
- Local-browser saving and loading

## Current limitations
This is the first playable prototype. Saves are stored in the current browser, so they do not sync between devices. Multiplayer, accounts, public worlds, and inviting friends are future milestones.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages**.
3. Under the build/deployment section, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to finish publishing and use the URL shown there.
